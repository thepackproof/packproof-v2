It validates every source SQL hash, the live identity of the **restored** PostgreSQL 16 owner connection, actual ECS task metadata, the immutable candidate image digest and verified RDS TLS. Set the clone host, database and login, a pinned CA file, `PACKPROOF_MIGRATE_ON_START=false` and `PACKPROOF_ORDER_WORKSPACE_ENABLED=false`. Bind the reviewed JSON object and its SHA-256 to `PACKPROOF_RESTORED_REVIEW_JSON` and `PACKPROOF_RESTORED_REVIEW_SHA256`.
