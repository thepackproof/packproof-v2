## Recovery

The S3 bucket is retained if the stack is deleted or replaced. Do not empty it to force stack deletion. An update rollback should be a new properly signed version; if an emergency metadata restoration is necessary, an infrastructure operator can recover a known-good version from S3 version history after rechecking signature/hash evidence. Publish roles intentionally have no version-delete or arbitrary version-restore privileges.

Before changing the template after deployment, use an UPDATE change set for this stack and review its exact resource impact. Never repurpose the existing website stack or distribution for desktop release hosting.
