# PackProof partner SDK for Python

Server-side Python 3.10 client using the standard library. This repository candidate is installed from a local checkout and is not published to a registry.

See the [tested integration quickstart](../../docs/api-portal-v1/QUICKSTART.md) and [SDK contract](../../docs/api-portal-v1/SDK.md). Keep service credentials in a secret manager or the server environment.

```text
python -m pip install ./packages/partner-sdk-python
python -m unittest discover -s packages/partner-sdk-python/tests -v
```
