# PackProof partner SDK for TypeScript and Node.js

Server-side Node.js 22 client with TypeScript declarations and no runtime dependencies. This repository candidate is installed from a local checkout and is not published to a registry.

See the [tested integration quickstart](../../docs/api-portal-v1/QUICKSTART.md) and [SDK contract](../../docs/api-portal-v1/SDK.md). Never place a service credential in a browser bundle.

```text
npm install ./packages/partner-sdk-typescript
node --test packages/partner-sdk-typescript/test/*.test.mjs
```
