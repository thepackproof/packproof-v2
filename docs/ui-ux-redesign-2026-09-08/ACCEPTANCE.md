## Rules for closing a row

Record exact final source SHA, environment/API commit/schema, command or observed task, timestamp, artifact/build ID, result, retained evidence reference and tester/device as applicable. Do not overwrite an earlier failure without recording its correction and rerun. A disabled, skipped or inaccessible scenario is not a pass. T03–T05 explicitly require real installed-device evidence; T21 and the usability gate likewise cannot be closed by source tests.

If one shared fixture supports multiple rows, reference it from those rows instead of inventing duplicate observations. Keep raw labels, addresses, media, credentials, biometric samples and personal identifiers out of this general ledger; use restricted evidence references for sensitive originals.
