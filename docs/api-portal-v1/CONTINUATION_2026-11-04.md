## Implemented in source

- Organization-service CSV preview, explicit commit, durable row outcomes and canonical export operations are mounted with current originating credential/delegation, source, operator and location checks.

The frozen manifest, explicit omissions, source originals, independent verifier and protected worker profile retain separate trust and qualification gates. - Deletion impact, service-attributed requests and human review use the existing authoritative request table. Fresh impact digests, current holds and retention constrain review. Physical deletion, backup erasure and downstream-copy recall are explicitly unavailable.
- Administrators can publish immutable requirement sets and review/assign an exact version to a record or item using ordinary portal fields. Rule definitions, digests, assignments, due times, reasons and recovery facts persist. Later publication never rewrites earlier requirements. A generic existing file is not represented as a photo, signature or physical condition finding.
- Typed item allocations bind explicit current packages/pallets within the same record. Quantities use decimal strings and exact rational conversions with a versioned rule and declared absolute/relative tolerances. Unknown units, dimensional conflicts and duplicate references require review; no product pack size or ambiguous match is guessed. Corrections preserve history and refuse implicit supersession branches.
- Review responsibility can be assigned to a currently eligible member by a human administrator or a narrowly scoped issues:assign service. Routing preserves immutable history, real actor identity and a snapshot-covered review note. It does not resolve the issue, confer access or impersonate the assignee.
- Node/TypeScript and Python clients cover imports, resumable source uploads, exports, snapshots, shares, deletion reviews, exact reference matching and review routing. The generated contract describes 119 mounted records operations and 145 total OpenAPI operations.
- Source-bound API/worker privilege planning covers migrations 096–107. Workers receive read access to metadata needed for recovery reconstruction, while human requirement/waiver/template decision writes remain unavailable to workers. No production role or grant was changed.
