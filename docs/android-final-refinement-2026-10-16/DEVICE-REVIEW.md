Required coverage from plan Section 6.1: approximately 360dp, 393dp and 412+dp; compact and tall heights; normal, 1.3x and 2.0x fonts; gesture and three-button navigation; keyboard open; long labels; TalkBack. Exercise libraries with 0, 1, 3 and 100 records, mixed roles/status and finalized records using authorized test fixtures. Record each actual device/configuration rather than claiming full matrix coverage from one run.

## Two complete journeys

1. Ordinary packing: open the intended Proof, start one continuous recording, save locally, upload, wait for the server receipt, complete the required attestation and server finalization, then reopen read-only. Check that the original is retained until the required receipt. Export and inspect the evidence package.
2. Grading: open the intended item, capture front then back, return from the camera, wait for acknowledged progression, and finish the remaining required steps. Interrupt network between save and acknowledgement, retry and relaunch; confirm the same capture action is reconciled without duplicate evidence or premature progression.

Record actual server acknowledgements and Proof IDs alongside the screen recordings. Do not mark a journey passed from a local success label alone.
