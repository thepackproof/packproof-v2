## Device and usability collection

Use dedicated test accounts and evidence. Record build SHA/version, device, OS, font scale, scenario, expected/actual result and video/screenshot location. Do not inject failures into customer evidence. Record current server capability/policy responses without secrets or evidence contents.

Run the plan's formative five-person round, resolve findings, then the fresh ten-person acceptance round. Count coaching as assistance. Required measures are purpose/start, unassisted completion, next-action comprehension, correct local-versus-server interpretation, finding the finished original and safe recovery. No cohort has been recruited or observed in this run; all human metrics remain blank.
