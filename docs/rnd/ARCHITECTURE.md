# R&D architecture and threat boundaries

The root remains the existing immutable transaction-bound Proof. An analysis extension references that root and never inserts newly received media into historical signed bytes. Outbound, receipt, return and return-receipt observations have explicit subject/leg/package identities; a replaced carton gets a new package identity.

## Common flow

Bound capture and durable local journal feed existing upload/commit. The server resolves immutable source inventory, queues bounded optional jobs and commits server-validated results into an ordered append-only extension chain. Authorized clients show sources, coverage, method, limitations and separate job/finding/assurance states. Exports include precise source/derivative omissions and independently executable verification material.

Source acquisition prioritizes original recording and recovery, then provenance, low-rate localization, selected original frames, and finally optional vision. Buffer pressure drops optional work. Native sidecars retain their own exact-byte digest and time relationship to encoded video; decoded frames carry decoder/extraction provenance. Temporal association is not byte equality.

The mobile agent extends the current Android/iOS owner; the backend agent extends existing monolith authorization, database and workers; vision tasks share decoded frames; privacy and witness records consume committed sources; learning remains an isolated consented research process. Shared contracts define the boundary before feature integration.

## Assurance separation

| Claim type | Evidence checked | Explicit limit |
|---|---|---|
| Byte integrity | Hashes, canonical manifests, signatures | Does not establish scene truth |
| App/request | Platform assertion, nonce binding, key trust | Does not attest photographed object or all camera buffers |
| Scene response | Qualified response to a fresh bounded challenge | Does not exclude every replay/injection or staged scene |
| Physical region | Frozen qualified comparison of named visible regions | Does not establish contents or unopened package |
| Event/condition | Source-backed visible interval/region | Does not establish unseen acts, cause, intent or liability |
| Witnessed history | Blinded commitment, inclusion/consistency, trusted witnesses | Does not establish statement truth or complete undisclosed history |

`FAILED` is operational and cannot become `DIFFERENCE_OBSERVED`. Absent later evidence is `NOT_CHECKED`; insufficient quality is `INCONCLUSIVE`; unsupported profile is `UNSUPPORTED`. Correlated channels are not independent votes. Label agreement with carton disagreement remains mixed evidence in API, viewer and export.

## Threat model

Untrusted parties include clients supplying scores or URLs, a participant requesting unrelated sources, replayed or reassigned session data, duplicate at-least-once jobs, malformed decoder inputs, malicious baseline enrollment, copied serials/labels, transferred regions, camera-buffer injection, omitted media, model poisoning and log equivocation.

Controls include server-bound subjects, participant/tenant checks before metadata access, immutable storage versions, exact-byte commitments, scoped idempotency identities, short leases/retries and resource limits, atomic outbox plus unique extension identity, detached signatures with pinned trusted keys, append-only corrections, isolated decoders/models, reviewed derivative exports, blinded log openings and separately managed witness trust.

Compromised capture devices can fabricate a scene before hashing. Synthetic fixtures cannot validate phone optics, real App Attest/Play Integrity, light safety, rare physical-copy errors or independent witness operation. These boundaries remain in every exported method profile and the qualification ledger.

## Isolation and migrations

Default research runtime is local-only, with separate database/storage namespace and development keys. Production credentials/endpoints are never a fallback. Feature collection, processing, internal display and customer display are independently default off; training still needs purpose/versioned consent. A global switch disables optional processing without interrupting original capture or normal Proof access.

Additive database constraints enforce source/analysis uniqueness, same-tenant relationships, a serialized extension sequence and immutable prior results. Large descriptors/geometry belong in private versioned artifact storage. New canonical extension schemas do not alter the legacy root serializer. Keys, receipt timestamps, monotonic offsets, device wall times and independent timestamps keep separate semantics.
