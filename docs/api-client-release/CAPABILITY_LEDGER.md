## Candidate identity and status vocabulary

Inspected source baseline: `thepackproof/packproof-v2` main **`e4f69c9a690649c41b846468eb48829fb0542617`**, Git tree **`a302d78537a6e506c5b3a51fb72b8631f1859f0d`**. This is a source identifier, not an assertion that the same image is currently deployed.

The October 28 integrated candidate and its immutable image/client identities must be recorded with the eventual commit and CI/release receipts. New candidate work listed below is **source implementation pending integrated validation**. No local execution, live device, provider, load, restore or security success is claimed by this ledger. A green historical test or source merge does not close a current release gate.

- **Implemented:** a reviewed source path exists; configuration and runtime success are separate.
- **Configured:** a dated observation establishes the exact environment, settings and resource identities without disclosing secrets. Configuration instructions alone do not establish this status.
- **Validated:** a named test/observation passed against an identified candidate and environment, within its stated scope.
- **Deferred:** deliberately outside the selected workflow or conditional on measured need.
- **Blocked:** a required dependency or observation is unavailable. This does not imply that unrelated authorized engineering should stop.

All rows below retain **current deployment/configuration unknown** unless a current receipt is added. Historical receipts are evidence only for their stated date, candidate and environment.

## Scope decisions retained

Use the modular monolith, PostgreSQL authority/outbox/leases, original object versions, supported Android/web capture and existing viewer. Preserve one canonical transaction/root Proof and distinct merchant context, integration assertions, PackProof facts and human attestations.

Async export jobs, a new broker, broader connectors, new iOS/desktop apps, AI fraud/claims products and a new cloud are not prerequisites. Add them only for demonstrated requirements. Conditional scope is deferred, not silently counted complete. No physical deletion or irreversible retention change is authorized by writing this ledger.
