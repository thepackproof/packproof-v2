## Tracking and native manifests

The inspected custom camera, document-preview and order-share manifests set `NSPrivacyTracking` to false with no tracking domains. No advertising purpose was found in the inspected flows. This is source evidence, not a completed audit of every dependency, provider or production setting. Shipment tracking is a product function and should not be confused with advertising tracking.

The manifests' empty `NSPrivacyCollectedDataTypes` arrays do **not** establish that the complete app collects no data. Their required-reason API entries cover local file metadata, disk-space checks and elapsed timing; App Store data-collection answers are a separate review.
