# PackProof V2 backend

Modular monolith. Domain commands own Proof state. HTTP only translates requests.

## Commands

- `createTransaction`
- `createOrGetProof`
- `createInvitation`
- `acceptInvitation`
- `initializeEvidenceUpload`
- `commitEvidence`
- `finalizeProof`
